# 🎙️ Career-Mock Voice based AI Interview Platform

🚀 **A next-generation career mock interview system powered by Artificial Intelligence and Voice Recognition.**

In today’s world, industries and companies are moving toward **AI-driven virtual interviews**.  
To contribute to this real-world transformation, I’ve developed an **AI-Based Voice Interview Platform** — a smart, interactive system designed to simulate real interview experiences for both recruiters and candidates.

---

## 🌟 Overview

This platform acts as a **career mock AI interview application**, bridging the gap between human interaction and artificial intelligence in recruitment.

It consists of **three main user roles**:

1. 👔 **Recruiter**
2. 🧑‍💼 **Candidate**
3. 🧑‍💻 **Admin**

Each role has distinct functionalities that ensure an efficient and automated interview process.

---

## 🧭 Application Flow

### 👔 Recruiter Panel
- Login securely using multiple sign-in methods (Google, Email, etc.) via **Supabase Authentication**.  
- Create and schedule interviews 🗓️  
- Generate and share **unique interview links** with candidates 🔗  
- View all **scheduled interviews** and **candidate performance** in real time 📊  
- Receive **AI-based performance feedback** for each candidate 🧠  

### 🧑‍💼 Candidate Panel
- Login to view the list of interviews assigned to them 📋  
- Start interviews directly using the **"Start Interview"** button 🎤  
- The **AI interviewer** (powered by VAPI) interacts with the candidate in real-time using voice-based communication 🗣️  
- **Grok AI** analyzes responses and provides evaluation and scoring for recruiters 🧩  

### 🧑‍💻 Admin Dashboard
- The **Admin** acts as the system supervisor with full control over activities.  
- Monitor all user logins, recruiter credits, and interview data 📈  
- Manage recruiter credits (each interview creation consumes one credit) 💳  
- View and manage all interviews created by recruiters 🗂️  
- Ban or delete users/interviews when necessary ⚙️  

---

## 🤖 AI & System Workflow

1. Recruiter creates an interview using **Grok AI** to generate intelligent questions.  
2. The questions are transferred to **VAPI Voice AI**.  
3. Candidate interacts with WAPI during the interview.  
4. WAPI analyzes the candidate’s **voice tone, confidence, and fluency**.  
5. Feedback is generated and sent back to **Grok AI**.  
6. **Grok AI** processes this feedback and updates it on the recruiter’s dashboard.  
7. Recruiter can review the performance and make hiring decisions accordingly.
